This repository contains the complete Jupyter Notebook and code used in the dissertation "The Effect of Feature Selection on Machine-Learning Classification Performance for Heart Disease Prediction Using the UCI Cleveland Dataset". The notebook covers the full analysis pipeline, including data loading and quality assessment, preprocessing (mode imputation, standardisation, and an 80:20 stratified train/test split), exploratory data analysis, four feature-selection methods (ANOVA, Mutual Information, Random Forest importance, and RFECV), and the training and evaluation of Logistic Regression, Random Forest, and SVM classifiers on both the full and RFECV-selected feature sets. The analysis was implemented in Python 3.10 using pandas, NumPy, scikit-learn, matplotlib and seaborn, with a fixed random seed (RANDOM_STATE = 42) throughout to support reproducibility. The dataset used is the Cleveland subset of the UCI Heart Disease dataset (Janosi et al., 1989), available at https://archive.ics.uci.edu/dataset/45/heart+disease.
